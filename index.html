Read-only: this page only shows what inverter_live.py reads from the inverter.
Real measurements of one MOD TL3-XH inverter (registers 3000-3180). Grid, load and charge power are the inverter's own view of the site connection, the SDM630 site meter is not read yet, so the figures need not add up exactly. The mode is derived from the measured power flows (CHARGE from grid = the battery charges while the grid delivers power; SELL = power flows to the grid); the schedule word is the inverter's own priority register 3144 (Load First / Battery First / Grid First).
